# Design System

<!-- impeccable:design-schema 1 -->

## Visual Language

- **Theme**: Refined, modern enterprise tech support desk. Clean white/slate backgrounds with vibrant indigo/blue key highlights, subtle radial gradients, and micro-glass elements.
- **Typography**: Inter / system-ui, balanced scale, tracking tuned (-0.02em on headings), high legibility.
- **Color Palette**:
  - Primary Accent: Blue-600 to Indigo-600 gradient highlights (`#2563eb` to `#4f46e5`).
  - Surface: Pure white cards with subtle slate borders (`#f8fafc`, `#f1f5f9`, `#e2e8f0`).
  - Text: High-contrast Slate (`#0f172a` primary, `#475569` secondary, `#64748b` muted).
  - Feedback: Rose for errors (`#e11d48`), Emerald/Indigo for status badges.
- **Elevation & Shadows**: Soft layered ambient shadows (`shadow-2xl shadow-indigo-500/5`), layered subtle borders.
- **Micro-Interactions**: Smooth scale-up on buttons, subtle focus ring glows, animated icon transitions, clean error shake alert.
